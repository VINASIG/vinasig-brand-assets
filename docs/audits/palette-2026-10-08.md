# Palette reconstruction review

Reviewed on 8 October 2026 for VINASIG Brand Assets.

## Task and source

The owner requested reconstruction from their submitted Minecraft color table, specifically asking for the unused Background column, allowing very bright Foreground colors to be skipped, and asking whether the existing palette was mainly material-derived.

The old current guide listed Scout Blue, Thinker Orange, Builder Green, Auditor Red, Core Graphite, Black and White. The five named identity colors match Material Lapis, Resin, Emerald, Redstone and Netherite Hex values. Neither that guide nor the preserved story contained the Background column. The SVG originals retain those identity Hex values.

The submitted HTML digest is recorded in [palette.json](../../assets/palette.json). We reconstruct factual color values in an authored JSON structure rather than redistribute the external HTML. The [source page](https://minecraft.fandom.com/wiki/Formatting_codes#Color_codes) is attributed. The source is an owner-provided snapshot, not a claim that the page or game has been freshly certified. Emerald and Resin RGB conflicts are explicitly retained and resolved by the existing identity Hex.

## Design decisions

Five existing identity colors remain primary. Five supporting colors and six neutrals add breadth. All 30 source Background values are available as exact dark primitives. Classic chromatic foregrounds and Minecoin Gold are traceable but excluded from selection. There are 45 unique selected Hex values after accounting for Black appearing in both columns.

The exclusion is subjective curation to fit the existing identity. It is not a scientific glare model or evidence of preference. Background in the source is text-shadow color, not a page-background prescription. The extra shadows are a reference library rather than 30 required application surfaces. Consumers should choose a small subset for an actual interface.

The source's two Gold shadows remain distinct. No lighter tint, opacity adjustment, interpolated ramp or invented replacement Hex is introduced. Source foreground and shadow correspondence is shown for provenance, with actual text contrast reported separately. Several correspondences fail normal-text AA. The five role colors therefore remain identity primitives, not a promise that every color can carry white text or serve as body text.

## Rights and delivery

The new palette source and official palette sheet follow the repository's existing identity-asset scope. LICENSES.md lists their paths explicitly. GPL-3.0-or-later still covers authored tooling. CC-BY-SA-4.0 still covers authored documentation. The unchanged Space Grotesk notice covers any existing font files. No new license grant, trademark ownership, personal author, Minecraft affiliation or third-party assignment is asserted.

The SVG contains no embedded font, copied logo artwork, active content or remote resources. Its literal colors and text geometry are generated from reviewed JSON. Available fonts may change glyph rendering. The authored source records numbers and source names and retains the source's two contradictions. Current archive metadata appends only the two new assets and retains all original catalog records and protected digests.

The render command cannot rewrite the asset catalog or archival evidence. Its check mode compares byte equality against the source. Existing typed lint, formatting, license and preservation gates remain active. Palette fixtures check malformed Hex and display names, identity mutation, source-code coverage, Gold variants, RGB correction metadata and changed exports. Contrast decisions use unrounded W3C sRGB ratios.

Official registry and release metadata were read on 2 October 2026; this adoption was completed on 3 October 2026. Asset consumers have no runtime dependency on these tools.

Sources are the official [Node.js release index](https://nodejs.org/dist/index.json), [Node.js release policy](https://nodejs.org/en/about/previous-releases), and npm registry metadata for [npm](https://registry.npmjs.org/npm/latest), [TypeScript](https://registry.npmjs.org/typescript/latest), [typescript-eslint](https://registry.npmjs.org/typescript-eslint/latest), [ESLint](https://registry.npmjs.org/eslint/latest), [@eslint/js](https://registry.npmjs.org/@eslint/js/latest), [Node types](https://registry.npmjs.org/@types/node) and [Prettier](https://registry.npmjs.org/prettier/latest).

Node and npm are pinned in `.node-version` and `package.json`; all development dependencies have exact versions and a committed lockfile. TypeScript runs with strict checking, unchecked-index protection and exact optional properties. ESLint uses `strictTypeChecked` with zero warnings. Source checks execute with Node's native type stripping and do not produce a distributable package.

The local verification uses a project-local Node 24.21.0 runtime whose downloaded archive was checked against the official `SHASUMS256.txt`. It does not change the computer's globally configured Node version. npm 12.2.0 can be bootstrapped explicitly with `npx --yes npm@12.2.0`; subsequent `npm` commands should use the same pinned version.

# VINASIG Logo System

Private archive for the VINASIG Logo System, version 1.0. The design record states that work started on 26 September 2026 and describes a hand-designed pixel-art logo developed into a broader identity system.

## Repository map

- 01_Logos: editable source files, source canvases, and exported logo variants.
- 02_Typography/Space Grotesk: third-party typeface files. The included OFL.txt applies to the font software.
- 99_Evidence: creation record, initial file inventory, SHA-256 list, and the PowerShell generator.
- VINASIG_Logo_Story.md: project story document from the original asset folder.

## Provenance and integrity

The evidence files preserve the project details and metadata available when the evidence package was prepared. SHA256SUMS.txt covers the 49 project files that existed before 99_Evidence was created. GENERATE_SHA256.ps1 regenerates checksums for files outside 99_Evidence.

The Git history and v1.0 release preserve this uploaded version. They provide an archival record, not an independent legal determination or a substitute for any formal registration process.

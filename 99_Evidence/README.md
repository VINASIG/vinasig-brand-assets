# Evidence package

This folder contains a dated project record and file integrity references for the VINASIG brand assets.

- CREATION_RECORD.md records the project details, design description, master sizes, and the source and exported logo files present when the evidence package was prepared.
- FILE_INVENTORY.md records the relative paths, byte sizes, and local modified timestamps of the files that existed before 99_Evidence was created.
- SHA256SUMS.txt contains SHA-256 checksums for those pre-existing project files. The entire 99_Evidence folder is excluded.
- GENERATE_SHA256.ps1 recreates SHA256SUMS.txt from the project root, excluding the entire 99_Evidence folder.
- README.md explains the contents of this evidence package.

No logo license is added by this package.
